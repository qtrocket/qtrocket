\part{The Graphical Interface (Planned)}\label{part:gui}

\begin{note}[Part II is not yet written]
The Qt6 GUI currently opens and saves \code{.qrd} designs, shows the part tree,
imports and searches motors, and flies the same simulations --- but rocket
\emph{authoring} (adding and editing parts) is CLI-only today. Part~II will be
written when the GUI's design editor lands. Until then, every workflow in this
guide is available through \code{qtrocket-cli}, and \code{.qrd} files saved from
the CLI open directly in the GUI and the visualizer.
\end{note}
